# Smart Pharma Icons / 智能医药图标

12 editable SVG icons for medical internet products, clinical dashboards, and pharmaceutical technology interfaces. Every standalone icon uses a `64 x 64` canvas, a transparent background, accessible title/description metadata, and a shared blue-cyan-green visual language.

## Usage

Use a standalone SVG as an image:

```html
<img src="./ai-diagnosis.svg" alt="AI 辅助诊断">
```

Or load `icon-sprite.svg` into the document and reference a symbol:

```html
<svg width="64" height="64" role="img" aria-label="AI 辅助诊断">
  <use href="./icon-sprite.svg#ai-diagnosis" />
</svg>
```

Core palette: blue `#2878FF`, cyan `#37C8F5`, green `#25D3A1`, ink `#18354F`.
