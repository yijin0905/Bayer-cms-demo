# Smart Pharma SVG Kit

An editable SVG asset set for intelligent pharmaceutical and digital health interfaces.

## Palette

- Background: `#FFFFFF`
- Medical blue: `#2878FF`
- Cyan: `#37C8F5`
- Health green: `#25D3A1`
- Deep ink: `#18354F`
- Cool gray: `#8194A7`
- Soft line: `#DCEAF2`

## Files

- `illustrations/`: Isometric, white-background scenes for hero areas and feature panels.
- `icons/`: UI icons supplied as independent 64 x 64 SVG files.
- `preview.html`: Local gallery with copy and download controls.

All artwork uses native SVG shapes, gradients, masks, and filters. Text labels in the illustrations are decorative fictional data and can be edited or removed.
